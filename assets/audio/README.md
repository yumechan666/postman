# Audio placeholders

These MP3 files are valid silent placeholders. Replace each file with the final
audio while keeping its filename; all paths are registered in `pubspec.yaml`.

## Music

- `bgm.mp3` — looping music used in the menu and during gameplay

## World ambience

`ambience_pollen.mp3`, `ambience_petal.mp3`, `ambience_spore.mp3`,
`ambience_rain.mp3`, `ambience_leaf.mp3`, `ambience_firefly.mp3`,
`ambience_steam.mp3`, `ambience_bubble.mp3`, `ambience_snow.mp3`,
`ambience_starfall.mp3`, `ambience_cloud_mote.mp3`,
`ambience_postal_sparkle.mp3`, and `ambience_rune.mp3` are selected from each
world's weather setting.

## Sound effects

`click`, `select`, `toggle`, `back`, `step`, `jump`, `land`, `hit`, `interact`,
`dialogue`, `pickup`, `drop`, `pet`, `puzzle_open`, `correct`, `wrong`, `hint`,
`error`, `letter`, `coin`, `star`, `unlock`, `level_start`, `win`, and
`ending`.

Run `python dummy/generate_postman_audio_placeholders.py` to regenerate the
silent files.
